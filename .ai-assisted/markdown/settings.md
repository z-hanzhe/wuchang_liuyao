# 设置

## 页面与职责

- `feature/settings/SettingsScreen.kt` 是设置总览，进入通用设置、排盘设置和排盘记录；`SettingsViewModel` 统一持有设置状态，`AppSettingsRepository` 使用 SharedPreferences 持久化。
- 通用设置包括字体大小、首页农历卡片、23 点换日、默认起卦方式、默认时间类型、自动保存条件和自动保存分组。
- 排盘设置包括天干与伏神展示、六神/六亲缩写、回头生克/冲合、日月冲合、旬空标记和地支点击高亮；这些开关只影响结果展示。

## 默认行为

- 默认显示农历卡片并开启 23 点换日，字体为标准比例，默认爻名起卦和公历时间。
- 自动保存默认关闭；排盘页的扩展展示、提示、旬空标记和点击高亮默认关闭。
- 自动保存支持关闭、问念非空和始终三种策略，目标分组无效时回退系统默认分组。

## 持久化与联动

- 枚举设置以枚举名保存，未知值回退默认；字体比例仍兼容旧版字符串档位。内部 key 和数值范围以 `AppSettingsRepository.kt`、`AppFontScale.kt` 为准，不在文档复制。
- 跨页即时同步语义集中在 `index.md`，实际消费方装配在 `WuchangLiuyaoApp.kt`。
- 新增设置时同时明确归属页面、默认值、持久化兼容策略和实际消费方；只有用户可见语义变化才更新本文。
