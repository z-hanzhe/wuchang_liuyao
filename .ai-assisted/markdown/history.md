# 历史记录

## 职责与入口

- `feature/history/HistoryViewModel.kt` 管理分组、搜索和批量操作，`HistoryScreen.kt` 负责列表交互；`data/history/DivinationHistoryRepository.kt` 是持久化边界。
- 历史页先展示分组，进入分组后展示记录；支持关键词搜索、记录多选、全选/反选、移动与删除，以及自定义分组的新建、重命名、排序、移动和删除。
- 组内记录按首次保存时间倒序，搜索只匹配问念；编辑或移动不改变创建时间，也不会把记录重新置顶。
- 返回按退出选择模式、清除搜索、返回分组列表、离开历史页逐层处理，系统返回与顶部返回保持相同语义。
- 历史页不直接编辑卦例；点击记录进入结果页后编辑问念、现状和断语。

## 分组规则

- 系统默认分组标识固定为 `default`，始终排在第一位且不可重命名、删除或参与自定义排序。
- 自定义分组名称去除首尾空白后必须非空且不重复。删除自定义分组会同时删除其中记录；移动分组记录和移动选中记录都要求目标分组仍存在。
- 设置中的自动保存分组引用历史分组；目标被删除后设置回退到默认分组。

## 持久化边界

- 当前使用 SharedPreferences 保存分组 JSON 与记录 JSON，不使用数据库。记录保存请求、完整结果快照、创建时间、所属分组、现状和断语。
- 历史仓库 API 是同步的，由 History/Result ViewModel 在 IO 调度器调用；Settings 为读取自动保存分组会同步访问同一仓库。
- 快照兼容、损坏数据和判重规则集中在 `index.md`；序列化变更应先更新兼容读取，再写入新格式。
